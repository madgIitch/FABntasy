# FABntasy 1.0.0 — 2026-09-15

Primera versión productiva de la PWA: autenticación, competición y jornada, equipo fantasy, mercado, ligas privadas, puntuación/rankings, notificaciones, administración de ingesta y correcciones auditables. Incluye operación por artefactos inmutables, HTTPS endurecido, backups cifrados/restores verificados, observabilidad, rollback compatible y aislamiento multi-temporada. Este changelog no contiene datos de usuarios, identificadores operativos ni secretos.
